# 誕生日カウントダウン&マイルストーンタイマー

誕生日や記念日までの日数・時間・分・秒をリアルタイムでカウントダウン表示するアプリ。複数のイベントを管理でき、当日にはお祝いエフェクトが発動する。

## 機能
- イベント名・日付・メモ・絵文字アイコンを設定して複数イベントを登録
- 日・時間・分・秒のリアルタイムカウントダウン（毎秒更新）
- 残り10日未満でカードの背景が脈動するアニメーション演出
- 当日（カウントダウン0秒）でカラフルな紙吹雪アニメーション
- 全画面モード（ESCキーで終了）で1イベントを大画面表示
- 過去のイベントは「○年前」として記録表示
- localStorageにイベントデータを保存・削除機能付き
